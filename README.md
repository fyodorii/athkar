# أذكار ومواقيت — تطبيق ويب للآيفون

تطبيق ويب يُثبَّت على الشاشة الرئيسية للآيفون من Safari، ويعمل دون إنترنت. لا يحتاج بناءً ولا مكتبات:
الملفات في هذا المجلد تُرفع كما هي.

## ما فيه

| القسم | المحتوى |
|---|---|
| **الرئيسية** | ساعة حية، والتاريخ الهجري (أم القرى) والميلادي، والصلاة القادمة بعدّ تنازلي، ومواقيت اليوم مع منتصف الليل والثلث الأخير، و«عباداتي اليوم» لتسجيل الصلوات بلمسة، وبطاقات **آية اليوم** و**حديث اليوم** و**نصيحة اليوم** و**ذكر اليوم** |
| **الأذكار** | الصباح، والمساء، وبعد الصلاة، والنوم، والاستيقاظ، والأذان والمسجد، والمنزل والسفر، والهم والكرب، وأدعية القرآن، والتسبيح؛ لكل ذكر عدّاد وفضله ومصدره، مع الحفظ والنسخ والمشاركة. و**أذكاري**: أذكارك الخاصة بعدد يومي وتذكير بوقت تختاره |
| **السبحة** | عدّاد بأهداف ٣٣ و٩٩ و١٠٠ و١٠٠٠ أو بلا حد، وتسبيح اليوم والمجموع، وأذكار تضيفها بنفسك |
| **عباداتي** | متابعة يومية: الصلوات الخمس (صليتها، أو في جماعة)، والرواتب، والضحى، والوتر، وقيام الليل، وورد القرآن بهدف يومي، والأذكار (تُسجَّل تلقائياً عند إتمامها)، والصيام، والصدقة وغيرها، مع آخر سبعة أيام وعدد الأيام المتتالية على الصلوات، وعبادات تضيفها بنفسك |
| **دفتري** | أدعيتك الخاصة بتصنيفاتها وتثبيتها، وكل ذكر حفظته من قسم الأذكار، مع البحث |
| **القبلة** | بوصلة تدور مع الجوال، وزاوية القبلة، والمسافة إلى مكة (الزر في أعلى الرئيسية) |
| **الإعدادات** | الموقع (تلقائي أو من قائمة مدن)، وطريقة الحساب (أم القرى وغيرها) ومذهب العصر وتعديل الدقائق، وتعديل الهجري، والمظهر الفاتح والداكن، وحجم الخط، والنسخ الاحتياطي |

مواقيت الصلاة تُحسب على الجهاز نفسه (`js/prayer.js`)، فلا تحتاج إنترنت.
كل بيانات المستخدم محفوظة على جهازه فقط (localStorage)، ويمكنه تصدير نسخة احتياطية واستعادتها.

## الرفع إلى الموقع

1. شغّل `npm run zip:adhkar` في جذر المستودع، فيخرج `adhkar-web-app.zip`.
2. في cPanel ← File Manager، ارفعه إلى `public_html` وفك ضغطه **مع الاستبدال**، فيصير التطبيق في
   `https://www.al-amen.com/adhkar/` (الملف المضغوط لا يحوي `push/data`، فلا تُمسح المفاتيح ولا الاشتراكات).
3. عدّل `push/config.php` على الخادم: البريد، و`CRON_KEY` (نص عشوائي طويل).
4. افتح `https://www.al-amen.com/adhkar/push/check.php?key=CRON_KEY` وتأكد أن كل البنود ✔،
   وانسخ أمر cron الظاهر في الصفحة إلى cPanel ← Cron Jobs على **مرة كل دقيقة** (`* * * * *`)
   حتى تصل تنبيهات الأذان في وقتها.
5. عند كل تحديث للتطبيق ارفع رقم `VERSION` في `sw.js`، فتجلب الأجهزة الملفات الجديدة.

على الآيفون: افتح الرابط في Safari ← زر المشاركة ← **إضافة إلى الشاشة الرئيسية**، ثم افتحه من أيقونته.

## الإشعارات

آبل لا تسمح لتطبيقات الويب بجدولة إشعارات على الجهاز، فالتطبيق يحسب جدول التنبيهات لثلاثين يوماً
(`js/schedule.js`) ويرسله إلى `push/subscribe.php`، و`push/cron.php` يرسل كل تنبيه في وقته عبر Web Push
(iOS 16.4 فأحدث، والتطبيق مثبّت على الشاشة الرئيسية). يُحدَّث الجدول كلما فُتح التطبيق، وإذا قارب
على الانتهاء يصل المستخدم تنبيه بفتح التطبيق مرة.

| الملف | عمله |
|---|---|
| `config.php` | الإعدادات |
| `check.php` | صفحة فحص بعد الرفع، وتعرض أمر cron |
| `cron.php` | يرسل التنبيهات المستحقة؛ يُشغَّل كل دقيقة |
| `subscribe.php` / `key.php` / `pending.php` | يستعملها التطبيق |
| `data/` | المفاتيح وملف لكل جهاز في `data/subs/`، محمي بـ `.htaccess` |

التنبيهات المتاحة: الأذان لكل صلاة، وقبل الأذان، والشروق، وأذكار الصباح والمساء والنوم، والصلاة على النبي ﷺ،
والجمعة، وصيام الاثنين والخميس، والأيام البيض، والثلث الأخير، ومتابعة العبادات، وتذكير كل ذكر في «أذكاري».
وحين يكون التطبيق مفتوحاً يظهر التنبيه داخله مع نغمة خفيفة.

## الويدجت

تطبيقات الويب لا يمكنها إضافة ويدجت على iOS، لذلك يولّد التطبيق (الإعدادات ← ويدجت الشاشة الرئيسية)
كوداً لتطبيق **Scriptable** المجاني (`js/widget.js`) فيه موقع المستخدم وإعداداته، ويحسب المواقيت
والتاريخ الهجري دون إنترنت. يدعم الأحجام الصغير والمتوسط والكبير، وويدجت شاشة القفل.

## المعاينة

تُنشر مع معاينة GitHub Pages على `https://fyodorii.github.io/alamen-app/adhkar/`. الإشعارات فيها
تستعمل خادم `al-amen.com/adhkar/push/` (انظر `js/config.js` و`ALLOWED_ORIGINS` في `push/config.php`).

## المحتوى

الأذكار في `js/adhkar-data.js` من الكتاب وصحيح السنة (أغلبها من «حصن المسلم») مع مصادرها، والآيات والأحاديث
والنصائح اليومية في `js/daily-data.js`. يُستحسن أن يراجعها طالب علم قبل النشر. أرقام الأذكار (`id`) تُحفظ
مع تقدّم المستخدم، فلا تُعِد استعمال رقم محذوف.
